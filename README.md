# Uwademm — website toko

Website statis dengan HTML, CSS, dan JavaScript terpisah. Tidak memerlukan instalasi atau build step.

## Menjalankan secara lokal

1. Buka `index.html` langsung di browser, atau gunakan ekstensi Live Server di editor.
2. Untuk mengaktifkan pemesanan WhatsApp, buka `script.js` dan ganti `628XXXXXXXXXX` dengan nomor bisnis. Gunakan format internasional tanpa `+` atau spasi.
3. Ganti placeholder `Nama aroma 01–03` dan `Rp XX.XXX` di `index.html` dengan detail produk yang sebenarnya.

Ilustrasi botol dibuat dari CSS sebagai visual konsep 3D, bukan foto atau klaim bentuk kemasan asli. Font diambil dari Google Fonts; ketika offline, website memakai font fallback sistem.
